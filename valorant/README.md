# Valorant's kill sounds and kill banners

The files for the Valorant packs in [Shell Shockers Valorant Kill Sounds](../README.md): Valorant's own kill sounds and kill banners from fifteen finisher bundles.

| Folder | Pack |
|---|---|
| `default` | Valorant Default |
| `reaver` | Reaver |
| `prelude` | Prelude to Chaos |
| `primordium` | Primordium |
| `sovereign` | Sovereign |
| `kuronami` | Kuronami |
| `evori` | Evori Dreamwings |
| `champions2021` | Champions 2021 |
| `gaia` | Gaia's Vengeance (Episode 7), blue variant |
| `recon` | Recon |
| `blackthorn` | Blackthorn |
| `cyrax` | CYRAX |
| `singularity` | Singularity (Episode 9) |
| `prime2` | Prime//2.0 |
| `sentinels` | Sentinels of Light |

Each folder has `1.mp3` to `5.mp3` and `1.png` to `5.png`: the sound and the banner for each kill in a streak, the 5th being the ace. The script downloads a pack from here the first time you pick it.
